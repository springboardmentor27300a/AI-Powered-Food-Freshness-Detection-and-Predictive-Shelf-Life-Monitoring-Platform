# API Documentation

Full interactive docs (auto-generated by FastAPI from the Pydantic schemas)
are always available at **`http://localhost:8000/docs`** (Swagger UI) or
**`/redoc`** once the backend is running. This file is a quick-reference
summary of what's new in Milestone 2/3 — Milestone 1's `/api/auth`,
`/api/users`, `/api/food`, `/api/batches`, `/api/inventory`, `/api/admin`
are unchanged.

All endpoints below require a valid JWT (`Authorization: Bearer <token>`)
obtained from `POST /api/auth/login`, except where noted.

## Images — `/api/images`

| Method | Path | Roles | Description |
|---|---|---|---|
| GET | `/model-status` | any | Whether the trained CNN is available |
| POST | `/upload?batch_id=<uuid>` | Quality Inspector, Admin | Multipart image upload |
| POST | `/{image_id}/analyze` | Quality Inspector, Admin | Runs CNN + OpenCV, returns both results |
| GET | `/batch/{batch_id}` | any | List images for a batch |
| GET | `/{image_id}` | any | Image metadata |

## Reports — `/api/reports`

| Method | Path | Roles | Description |
|---|---|---|---|
| POST | `/generate` | Quality Inspector, Admin | Runs shelf-life + scoring + recommendations, saves a FreshnessReport |
| GET | `` | any | List, with `page`, `page_size`, `category`, `batch_id`, `date_from`, `date_to`, `sort_by`, `sort_dir` |
| GET | `/{report_id}` | any | Full report detail |
| GET | `/{report_id}/pdf` | any | Downloads `FoodCare_Freshness_Report_<number>.pdf` |
| GET | `/{report_id}/csv` | any | CSV export |

## Shelf Life — `/api/shelf-life`

| Method | Path | Roles | Description |
|---|---|---|---|
| POST | `/batch/{batch_id}/estimate` | Retail Mgr, Warehouse Op, Inspector, Admin | Recomputes and saves an estimate |
| GET | `/batch/{batch_id}` | any | Full history |
| GET | `/batch/{batch_id}/latest` | any | Most recent estimate |

## Storage — `/api/storage`

| Method | Path | Roles | Description |
|---|---|---|---|
| POST | `/readings` | Warehouse Op, Admin | Log a temperature/humidity reading |
| GET | `/readings` | any | Filter by `batch_id`, `storage_location` |
| GET | `/trends?storage_location=...&days=7` | any | Time series for a location |

## Recommendations — `/api/recommendations`

| Method | Path | Roles | Description |
|---|---|---|---|
| GET | `/batch/{batch_id}` | any | List recommendations for a batch |
| POST | `/batch/{batch_id}/generate` | Retail Mgr, Warehouse Op, Inspector, Admin | Regenerate from current data |

## Analytics — `/api/analytics`

| Method | Path | Roles | Description |
|---|---|---|---|
| GET | `/inventory` | any | Category counts, expiring/expired/low-stock counts |
| GET | `/freshness` | any | Report counts by category, average score, recent reports |
| GET | `/storage` | any | 7-day compliance stats |
| GET | `/platform` | Admin | Everything above + user counts + model status |

## Error handling

All endpoints return standard FastAPI/Pydantic validation errors (422) for
bad input, 401 for missing/invalid auth, 403 for wrong role, 404 for
missing resources, and 500 with a message (never a silent failure) for
PDF generation or model-loading errors.
